# Conformance fixtures

This directory contains language-neutral fixtures used to characterize the
current Python RAG runtime and to prove parity during the hexagonal API
migration.

The retained assets are:

- `baselines/`: per-stage snapshots generated by the Python pipeline;
- `contracts/`: JSON schemas for stable stage boundaries;
- `queries.*.jsonl` and `seeds/`: deterministic query sets;
- `thresholds.json`: comparison thresholds for an OpenAI-compatible candidate;
- `reports/`: ignored output directory for local comparisons.

The retired TypeScript candidate-specific workflows, replay cache, thresholds,
and stage-report summarizer were removed. The Python baseline dumper and generic
comparison runner remain available for the next API implementation.

## Generate Python stage baselines

This command needs the configured database and model providers:

```bash
uv run python scripts/dump_stage_baselines.py \
  --queries-file tests/conformance/queries.sample.jsonl \
  --output-dir tests/conformance/baselines/queries-sample
```

## Compare with an OpenAI-compatible candidate

```bash
uv run python scripts/run_candidate_conformance.py \
  --queries-file tests/conformance/queries.sample.jsonl \
  --candidate-base-url http://localhost:8000 \
  --candidate-model assistant-rh \
  --output tests/conformance/reports/python_vs_candidate.json
```

Omit `--candidate-base-url` to capture a Python-only reference report.
